# My personal [website](https://skyfonix.cigoria.eu)!
Source code for my personal website!

## Current "features"
- A basic navbar that links to sections on the page
- Hero with an animated piece of text
- A collection of my most recent projects in cards
- About me section, with a couple of link to my socials
- Everything is dynamically rendered from a backend with a databse
- Gallery section with a working tagging system and metadata extraction, uploads done from a dashboard

## Planned features
- Some kind of blog so I can write about my projects/ make guides for my friends

## Tech stack:
- Node.js
- Express.js
- Prisma ORM
- React + React Router Dom
